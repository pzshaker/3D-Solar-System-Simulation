# 🚀 3D Space Exploration Simulator

A 3D interactive space simulation developed in **C++** using **OpenGL**, featuring a realistic solar system and dynamic gameplay elements. Navigate a spaceship through space, collect fuel tanks, and avoid asteroids in an immersive environment.

## 🌟 Features

- 🌍 **Realistic Solar System**: Planets orbit the Sun with self-rotation.  
- 🚀 **Spaceship Navigation**: Smooth and responsive controls for exploring space.  
- ⛽ **Fuel Mechanics**: Collect fuel tanks to maintain spaceship energy.  
- ☄️ **Asteroid Obstacles**: Avoid collisions with randomly placed asteroids.  
- 🌌 **Immersive Skybox**: High-quality space backdrop for realistic exploration.  
- 💡 **Dynamic Lighting**: Real-time lighting effects for planets and objects.
